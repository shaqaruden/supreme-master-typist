# Dvorak movement practice

Approved scope: optional exercises for Dvorak levels 2–6 only, excluding level 1, All Words and sentences. Each three-letter sequence is familiar → newly introduced → the same familiar key, entirely on one hand. Familiar keys come from earlier levels. New keys follow the actual Dvorak level dictionary and physical key positions.

Reuse the existing 20-item drill flow, retaining normal settings for exit. Offer both hands, left only or right only; omit unavailable hands (level 5 adds only right-hand keys). Group sequences by new key to introduce one reach at a time, vary starting keys, and keep both directions in every sequence. Provide a clear exit and keep movement results separate from normal tests and mistake drills. Movement practice cannot earn skill ranks.

Normal practice, other layouts, typing input and Game Mode behavior remain intact. The exercise is a focused transition aid; transfer to ordinary typing remains the practical measure of usefulness.

Follow-up: both-hand practice interleaves sides throughout the drill, randomizing which hand leads each pair. Each individual return remains on one hand; each hand retains its new-key progression.
